Description du Problème

Plateforme de Colocation – Côte d'Ivoire

🎯

Contexte

En Côte d'Ivoire, particulièrement à Abidjan et dans les grandes villes universitaires (Bouaké, Grand-Bassam, Yamoussoukro…), un nombre croissant d'étudiants et de jeunes travailleurs recherchent des solutions de logement abordables. La colocation apparaît comme une alternative intéressante face à la cherté des loyers et à la rareté des logements individuels adaptés aux budgets modestes.

Problème identifié

Actuellement, il n'existe pas de plateforme dédiée et structurée permettant de trouver ou de proposer facilement une colocation de manière fiable. Les personnes intéressées ont principalement recours à :

  • Des groupes Facebook et WhatsApp peu organisés
  • Des annonces dispersées sur les réseaux sociaux
  • Le bouche-à-oreille

Ces méthodes présentent plusieurs limites majeures :

  • Manque de filtres de recherche pertinents (budget, quartier, mode de vie, etc.)
  • Absence de système de compatibilité entre colocataires
  • Risques élevés d'arnaques et d'informations non fiables
  • Difficulté à évaluer le profil et le mode de vie des potentiels colocataires
  • Processus de recherche long, désorganisé et peu sécurisé

Conséquences

⏱️
Perte de temps importante pour les chercheurs de logement
⚔️
Colocations mal assorties (conflits de mode de vie, problèmes d'hygiène)
🚨
Sentiment d'insécurité lié aux arnaques fréquentes
📉
Sous-exploitation du potentiel de la colocation comme solution accessible

Objectif du projet

Le projet vise à répondre à ce besoin en proposant une plateforme web dédiée à la colocation en Côte d'Ivoire. Elle permettra aux utilisateurs de publier ou de rechercher des colocations selon des critères précis, tout en intégrant un système de matching basé sur la compatibilité des profils (budget, mode de vie, habitudes, préférences…), afin de faciliter des mises en relation plus pertinentes, plus rapides et plus sécurisées.

Algorithme de Matching

Plateforme de Colocation – Côte d'Ivoire

🤝

Principe général

L'algorithme calcule un score de compatibilité (de 0 à 100 %) entre le profil de la personne qui cherche une colocation et chaque annonce. Le score final est une moyenne pondérée des différents critères.

Fonctions de calcul (Python)

def score_budget(budget_chercheur, loyer_annonce, charges=0):
    total = loyer_annonce + charges
    if total <= budget_chercheur:
        return 100
    difference = total - budget_chercheur
    if difference <= 20000:      # 20 000 FCFA de marge
        return 80
    elif difference <= 40000:
        return 50
    else:
        return 0

def score_quartier(quartier_chercheur, quartier_annonce, ville_chercheur, ville_annonce):
    if ville_chercheur != ville_annonce:
        return 0
    if quartier_chercheur == quartier_annonce:
        return 100
    quartiers_proches = {
        "Cocody": ["Riviera", "Angré", "2 Plateaux"],
        "Riviera": ["Cocody", "Angré"],
        "Yopougon": ["Songon"],
    }
    if quartier_annonce in quartiers_proches.get(quartier_chercheur, []):
        return 70
    return 30

def score_exact(valeur1, valeur2):
    if valeur1 is None or valeur2 is None:
        return 70
    return 100 if valeur1 == valeur2 else 0

def score_mode_vie(mode1, mode2):
    if mode1 == mode2:
        return 100
    compat = {
        ("calme", "mixte"): 70,
        ("social", "mixte"): 70,
        ("calme", "social"): 20,
    }
    return compat.get((mode1, mode2), 20) or compat.get((mode2, mode1), 20)

Fonction principale

def calculer_compatibilite(chercheur: dict, annonce: dict) -> int:
    scores = {
        'budget': score_budget(chercheur['budget_max'], annonce['loyer'], annonce.get('charges', 0)),
        'quartier': score_quartier(chercheur.get('quartier'), annonce.get('quartier'),
                                     chercheur.get('ville'), annonce.get('ville')),
        'mode_vie': score_mode_vie(chercheur.get('mode_vie'), annonce.get('mode_vie')),
        'fumeur': score_exact(chercheur.get('fumeur'), annonce.get('fumeur')),
        'animaux': score_exact(chercheur.get('animaux'), annonce.get('animaux')),
        'type_chambre': score_exact(chercheur.get('type_chambre'), annonce.get('type_chambre')),
    }
    poids = {
        'budget': 0.25, 'quartier': 0.20, 'mode_vie': 0.15,
        'fumeur': 0.10, 'animaux': 0.10, 'type_chambre': 0.08,
    }
    score_final = sum(scores.get(c, 50) * p for c, p in poids.items())
    return round(score_final)

README du Projet

ColocCI – Plateforme de Colocation en Côte d'Ivoire

📖

Description

ColocCI est une plateforme web destinée aux étudiants et jeunes travailleurs en Côte d'Ivoire. Elle permet de trouver ou de proposer facilement une colocation grâce à un système de recherche avancée et un algorithme de matching basé sur la compatibilité des profils.

Objectifs du projet

  • Faciliter la recherche de colocation de manière structurée et sécurisée
  • Réduire les risques d'arnaques présents sur Facebook/WhatsApp
  • Proposer un score de compatibilité entre colocataires
  • Offrir une expérience moderne et adaptée au contexte ivoirien
